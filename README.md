# shop-mcp

MCP-сервер для поиска на Авито, Ozon и AliExpress под своим аккаунтом. Он управляет обычным Chrome, в котором вы уже вошли на эти сайты, и отдаёт результаты компактным TSV, а не снимками страниц. Так поиск стоит сотни токенов, а не десятки тысяч.

Что умеет:

- Авито: поиск с ценой доставки в ваш город и итоговой суммой, карточка объявления с адресом, фотографии галереи через `avito_item_images`.
- Мессенджер Авито: список чатов, переписка в чате, отправка текстового сообщения в чат или продавцу объявления.
- Ozon: поиск, карточка товара (характеристики, дата доставки, продавец и его юрлицо: видно, из-за рубежа ли товар), корзина (положить, посмотреть, убрать), история заказов с поиском по названию товара.
- AliExpress: поиск, карточка с датами и ценой доставки по вариантам, корзина, история заказов с поиском по названию товара.
- Отзывы на Ozon и AliExpress: список купленного, что ждёт отзыва, и отправка отзыва с оценкой и текстом.
- Чтение отзывов на товар Ozon и AliExpress: с сортировкой по полезности или с низких оценок и поиском по словам.

Заказы сервер не оформляет и ничего не оплачивает: Ozon и AliExpress заканчиваются на корзине.

## как устроено

Chrome запущен с отдельным профилем и `--remote-debugging-port=9222` на 127.0.0.1. Сервер подключается к нему по DevTools Protocol, держит по одной вкладке на сайт и вызывает собственное API сайта через `fetch()` изнутри вкладки. Cookies и авторизация остаются в профиле Chrome, в коде их нет.

У меня Chrome и сервер живут на отдельном Mac mini, а Claude Code ходит к нему по ssh. Запускать можно и на той же машине.

## установка

1. Запустить Chrome с отдельным профилем и отладочным портом, например LaunchAgent `~/Library/LaunchAgents/local.shop-chrome.plist`:

   ```xml
   <?xml version="1.0" encoding="UTF-8"?>
   <!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
   <plist version="1.0"><dict>
   <key>Label</key><string>local.shop-chrome</string>
   <key>ProgramArguments</key><array>
   <string>/Applications/Google Chrome.app/Contents/MacOS/Google Chrome</string>
   <string>--user-data-dir=/Users/YOU/Library/Application Support/shop-chrome</string>
   <string>--remote-debugging-port=9222</string>
   <string>--remote-debugging-address=127.0.0.1</string>
   <string>--no-first-run</string>
   <string>--restore-last-session</string>
   </array>
   <key>RunAtLoad</key><true/>
   <key>KeepAlive</key><true/>
   <key>LimitLoadToSessionType</key><string>Aqua</string>
   </dict></plist>
   ```

2. В этом Chrome войти на avito.ru, ozon.ru и aliexpress.ru и указать адрес доставки.
3. Положить репозиторий в `~/shop-mcp`. Нужен [uv](https://docs.astral.sh/uv/): зависимости описаны в заголовке `server.py`.
4. Подключить к Claude Code:

   ```sh
   # на той же машине
   claude mcp add shop -s user -- ~/shop-mcp/run.sh
   # на другой машине по ssh
   claude mcp add shop -s user -- ssh HOST ~/shop-mcp/run.sh
   ```

Лог вызовов пишется в `logs/shop.log`, тела неудачных ответов — в `logs/bodies/`. В них бывают ваши данные со страниц сайтов, поэтому `logs/` в `.gitignore`.

## мониторинг Авито в Telegram

`watch.py` ищет по всей России с Авито Доставкой новые Orange Pi Zero3 для пульта фрезера, у которых цена с доставкой не больше 5 000 ₽ (с 11.10.2026, до этого искал Raspberry Pi 4 и 5). Память любая, сверху дешёвые. Зарезервированные пропускает. Каждое объявление присылает один раз. Запросы и порог цены задаются в начале файла.

1. Создать бота у @BotFather и положить токен в `telegram.json`: `{"token": "..."}`.
2. Написать боту /start и выполнить `python3 tg.py setup`: скрипт найдёт ваш chat id и пришлёт тестовое сообщение.
3. Поставить расписание (10:07 и 20:07):
   ```sh
   cp launchd/local.shop-watch.plist ~/Library/LaunchAgents/
   launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/local.shop-watch.plist
   ```

Проверить без отправки: `uv run --script watch.py --print`.

## история заказов

`ozon_orders` и `ali_orders` ищут по названиям купленных товаров: `query` — слова, которые все должны встретиться в названии или варианте. Несколько вариантов можно искать за один вызов через «|»: `usb хаб | hub`. В списках заказов обоих сайтов названий нет, поэтому сервер открывает каждый заказ отдельным запросом, примерно по 1,5–2 с. Всё прочитанное лежит в `cache/orders.json`: завершённые заказы навсегда, заказы в пути на сутки (статус берётся из свежего списка), и сами списки заказов. Список обновляется сверху, пока не попадётся страница без новых заказов. Архив Ozon за прошлые годы после первого прочтения больше не запрашивается. Первый полный проход по нескольким сотням заказов занимает минут десять. Дальше обычный поиск идёт секунды, а повторный в течение 10 минут не делает ни одного запроса.

## фотографии Авито

`avito_item_images(url, limit=6)` отдаёт фотографии объявления как MCP-изображения
в порядке галереи, до 1280×960 px. Принимает полную ссылку или путь из `avito_search`.
`limit` — от 1 до 20; большие галереи требуют больше токенов. Фотографии помогают
проверить состояние, комплектацию и маркировку. При капче, отсутствии фото или ошибке
скачивания инструмент возвращает текстовое пояснение.

## мессенджер Авито

`avito_chats` показывает чаты, новые сверху, `unread_only=True` — только непрочитанные. `avito_chat` показывает переписку в одном чате. Оба читают через сокет самого мессенджера (`wss://socket.avito.ru`), который сервер открывает изнутри вкладки Авито, и не отмечают чаты прочитанными. Сокет живёт на странице и переиспользуется: новое соединение сразу после закрытого Авито не обслуживал.

`avito_send` отправляет текст от вашего имени: в чат по id из `avito_chats` или продавцу по ссылке на объявление. Сервер открывает чат на странице (у объявления — кнопкой «Написать сообщение»), вводит текст в поле и нажимает Enter, как человек. Потом ищет сообщение в истории чата и отвечает «отправлено» только если нашёл. Фото и файлы не отправляются.

## отзывы

`ozon_reviews_waiting` и `ali_reviews_waiting` показывают купленные товары, которые ждут отзыва. `ozon_leave_review` и `ali_leave_review` публикуют отзыв от вашего имени: оценку от 1 до 5 и текст. Сервер шлёт его тем же запросом, что и форма отзыва на сайте.

Ozon находит товар по sku. AliExpress — по строке заказа из списка, потому что один товар бывает в нескольких заказах. Фото и видео не прикладываются. Уже оставленный отзыв инструмент не редактирует.

Ozon при оценке ниже 4 требует текст. Если за отзыв на товар дают баллы, Ozon перед отправкой показывает условия. Тогда отзыв не уходит, а инструмент возвращает условия; отправить всё равно можно с `accept_conditions=True`. На AliExpress отзыв проходит модерацию, это до 48 часов.

В описании инструментов модели сказано брать оценку и смысл текста только у вас и показывать отзыв перед отправкой.

## чтение отзывов

`ozon_item_reviews` и `ali_item_reviews` показывают отзывы покупателей на товар: оценку, дату, автора, сколько человек сочли отзыв полезным, число фото и текст. Сортировка `useful` (полезные), `low` (с низких оценок), на Ozon ещё `high`, на AliExpress `new`. `query` оставляет отзывы со всеми словами одного из вариантов через «|», например `высота | центр`, и листает дальше первой страницы: на Ozon до 300 отзывов, на AliExpress до 80.

На Ozon продавцы склеивают разные товары под один рейтинг. По умолчанию инструмент показывает отзывы только на этот вариант (`reviewsVariantMode=1`), с `all_variants=True` — на все, и у чужих пишет, на какой товар отзыв. В шапке общий рейтинг и сколько отзывов на каждую оценку.

На AliExpress отзывы общие на карточку, вариант указан у каждого, ответ продавца идёт строкой ниже. API отдаёт по 10 отзывов за запрос, больше не принимает. Частые запросы вызывают проверку-слайдер: пока она открыта, Ali держит все запросы со вкладки. Сервер тогда через 25 с отвечает, что нужна проверка, и её надо пройти руками в Chrome на макмини.

## ограничения

- Сайты меняют вёрстку и API, и тогда разбор ломается.
- Авито при частых запросах включает проверку и отвечает 439. Сервер делает паузы между запросами, но капчу иногда приходится проходить руками в этом Chrome.
- Регион Авито по умолчанию — `sankt-peterburg`, меняется параметром `region`.
- Используйте на свой страх и риск: автоматизация может противоречить правилам сайтов.
